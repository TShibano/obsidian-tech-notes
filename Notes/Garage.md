## 概要

Garage は，フランスの Deuxfleurs コレクティブが開発する[[Rust]]製の S3 互換[[オブジェクトストレージ]]．小〜中規模の地理分散環境でのセルフホストを主眼に設計されており，異なる物理拠点にまたがるノード群でデータを複製しつつ，一部のノードが到達不能になっても可用性を維持することを目指す．

## 詳細

### 設計思想

Garage は「大規模データセンター向け」ではなく，複数拠点に少数のマシンを置く小規模コミュニティ・自宅サーバー・NPO 等の運用を想定している点が MinIO や Ceph と異なる．軽量で運用が容易であることを重視し，異種ハードウェア（性能差のあるマシン混在）や不安定なネットワーク環境でも動作するよう設計されている．

### 技術的特徴

- **CRDT（Conflict-free Replicated Data Types）**: 分散システム理論に基づき，ノード間の不要な通信を避けながら整合性を保つデータ構造を採用．合意形成のオーバーヘッドを抑えつつ高速に動作する
- **地理分散レプリケーション**: 複数の物理拠点にノードを配置し，拠点間でデータを複製．一部拠点がオフラインでも残りの拠点でサービス継続可能
- **S3 互換 API**: 既存の S3 クライアント・SDK・ツールがそのまま利用できる
- **軽量**: Rust で実装されており省メモリ・省リソースで動作するため，小規模ハードウェアでも運用可能

### 開発の背景と実績

Deuxfleurs は小規模な実験的セルフホストサービスプロバイダで，2020年の最初のリリース以来 Garage を自身の本番環境で運用し続けている．OSS（フリーソフトウェア）として公開されている．

### MinIO との比較

| 観点 | Garage | [[MinIO]] |
|------|--------|-----------|
| 想定規模 | 小〜中規模，地理分散 | 中〜大規模，単一データセンター/クラスタ想定が主 |
| 実装言語 | Rust | Go |
| 整合性モデル | CRDT ベースの結果整合性 | 強い整合性寄り |
| 運用の手軽さ | 異種ハードウェアでも運用しやすい設計 | 均質なクラスタを前提としやすい |

## ポイント

- Rust 製の S3 互換オブジェクトストレージで，地理分散・小規模セルフホストに特化
- CRDT を活用し，ノード間通信を抑えながら分散整合性を実現
- 2020年から Deuxfleurs 自身の本番環境で運用されている実績あり
- MinIO と同じ「セルフホスト S3 互換ストレージ」カテゴリだが，想定スケールと設計思想が異なる
