## 概要

Garage は，フランスの Deuxfleurs コレクティブが開発する[[Rust]]製の S3 互換[[オブジェクトストレージ]]（ライセンスは AGPLv3）．小〜中規模の地理分散環境でのセルフホストを主眼に設計されており，異なる物理拠点にまたがるノード群でデータを複製しつつ，一部のノードが到達不能になっても可用性を維持することを目指す．

## 詳細

### 設計思想

Garage は「大規模データセンター向け」ではなく，複数拠点に少数のマシンを置く小規模コミュニティ・自宅サーバー・NPO 等の運用を想定している点が MinIO や Ceph と異なる．軽量で運用が容易であることを重視し，異種ハードウェア（性能差のあるマシン混在）や不安定なネットワーク環境でも動作するよう設計されている．

### 技術的特徴

- **CRDT（Conflict-free Replicated Data Types）**: 分散システム理論に基づき，ノード間の不要な通信を避けながら整合性を保つデータ構造を採用．RAFT などの合意アルゴリズムでリクエストを順序付けないため，オーバーヘッドを抑えて高速に動作する
- **地理分散レプリケーション**: 複数の物理拠点にノードを配置し，拠点間でデータを複製．一部拠点がオフラインでも残りの拠点でサービス継続可能．多くの用途で `replication_factor = 3` が推奨されている
- **S3 互換 API**: 既存の S3 クライアント・SDK・ツールが利用できる．ただし S3 の全エンドポイントを実装しているわけではなく，対応範囲は公式の S3 互換ページで確認する
- **軽量**: Rust で実装されており省メモリ・省リソースで動作するため，小規模ハードウェアでも運用可能
- **スタンドアロン**: 外部サービスなしで動作する．ノードの追加・削除時は自動でリバランスされ，動的 IP にも対応する
- **圧縮と重複排除**: 固定長ブロックで保存して重複排除し，Zstd 圧縮を任意で有効化できる
- **静的ウェブサイト配信・バケットエイリアス**: バケットをそのままウェブサイトとして公開でき，ユーザーごとのローカルエイリアスも使える
- **運用機能**: 管理用 REST API，Prometheus メトリクス，OpenTelemetry トレース，Kubernetes / Nomad でのノード自動検出
- **K2V API（実験的）**: 小さなアイテムを大量に扱うためのキー/バリュー API

v2.0 での破壊的変更（公式マイグレーションガイドより）:

- 管理 API が全面的に作り直され，新エンドポイントは `/v2/` プレフィックスを使う．`/v1/` の一部呼び出しは残るが大半は動かないため，管理 API を使うコードは更新が必要
- 設定の `replication_mode` は廃止され，`replication_factor` と `consistency_mode` を使う
- 全ノードを同時に v2.0 で再起動すればほぼダウンタイムなしで移行できる．事前にメタデータのバックアップを取り，テーブルに対して `garage repair` を実行することが推奨される．v0.9.x 以前からの直接移行は非推奨

### 開発の背景と実績

Deuxfleurs は小規模な実験的セルフホストサービスプロバイダで，2020年の最初のリリース以来 Garage を自身の本番環境で運用し続けている．OSS（フリーソフトウェア）として公開されている．

### MinIO との比較

| 観点 | Garage | [[MinIO]] |
|------|--------|-----------|
| 想定規模 | 小〜中規模，地理分散 | 中〜大規模，単一データセンター/クラスタ想定が主 |
| 実装言語 | Rust | Go |
| 整合性モデル | CRDT ベースの結果整合性 | 強い整合性寄り |
| 運用の手軽さ | 異種ハードウェアでも運用しやすい設計 | 均質なクラスタを前提としやすい |

セルフホスト S3 互換ストレージには [[RustFS]]，[[SeaweedFS]] などの選択肢もある．

## ポイント

- Rust 製の S3 互換オブジェクトストレージで，地理分散・小規模セルフホストに特化
- CRDT を活用し，合意アルゴリズムを使わずに分散整合性を実現
- 2020年から Deuxfleurs 自身の本番環境で運用されている実績あり
- 2.x 系が現行（最新 2.5.0）．v1 系から上げる際は管理 API の `/v2/` 化と `replication_mode` 廃止に注意
- MinIO と同じ「セルフホスト S3 互換ストレージ」カテゴリだが，想定スケールと設計思想が異なる
