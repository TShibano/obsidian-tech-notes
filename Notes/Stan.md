## 概要

Stan は，[[ベイズ統計]]モデルの推定に特化した，C++で実装された確率的プログラミング言語．勾配情報を用いる[[HMC法]]の発展形である NUTS（No-U-Turn Sampler）をデフォルトのサンプリングエンジンとして採用しており，複雑な階層ベイズモデルでも効率的に事後分布を推定できる．社会科学・医薬統計・市場調査・医用画像など幅広い分野で利用される．

## 詳細

### 言語としての特徴

Stan は独自のモデリング言語であり，ユーザーは `.stan` ファイルにデータブロック・パラメータブロック・モデルブロックなどを宣言的に記述する．記述されたモデルは C++ コードにコンパイルされて実行されるため，純粋な Python/R コードでの実装に比べて高速に動作する．

```stan
data {
  int<lower=0> N;
  array[N] int<lower=0, upper=1> y;
}
parameters {
  real<lower=0, upper=1> theta;
}
model {
  theta ~ beta(1, 1);
  y ~ bernoulli(theta);
}
```

### 推定アルゴリズム

Stan は複数の推定アプローチを実装している:

| 手法 | 概要 |
|------|------|
| **NUTS（既定）** | HMC のステップ数を自動チューニングする MCMC．勾配ベースで高次元でも効率的に探索 |
| **確率的勾配変分ベイズ（ADVI）** | 近似ベイズ推論を高速に実行する変分推論手法 |
| **勾配ベース最適化** | ペナルティ付き最尤推定（MAP 推定など） |

自動微分によりモデルの勾配を計算するため，ユーザーが手動で微分を導出する必要がない．

### 複数言語からの利用

Stan 自体は独立したプログラミング言語だが，RStan（R），PyStan/CmdStanPy（Python），CmdStan（コマンドライン），brms（R の高レベル API）など，主要な統計解析言語からのインターフェースが整備されており，ユーザーは使い慣れた言語からモデルを呼び出せる．

### PyMC との使い分け

Stan はモデル記述用の専用言語を学ぶ必要がある一方，コンパイルされた実行が高速で，特に複雑な階層モデルでの実績・安定性が高いとされる．[[PyMC]] は Python ネイティブで記述できる手軽さが利点で，Python エコシステム（NumPy・pandas・ArviZ）との統合を重視するプロジェクトで好まれる．

## ポイント

- ベイズモデリングに特化した専用言語で，C++ にコンパイルされ高速に実行される
- NUTS（HMC の自動チューニング版）を既定のサンプラーとして採用
- ADVI による変分推論，勾配ベース最適化による MAP 推定にも対応
- R（RStan/brms）・Python（PyStan/CmdStanPy）など複数言語からのインターフェースがあり，専用言語のモデルを様々な環境から利用できる
- 複雑な階層ベイズモデルでの実績が豊富で，社会科学・医薬統計等の分野で広く採用
