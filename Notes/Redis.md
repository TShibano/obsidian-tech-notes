## 概要

Redis（Remote Dictionary Server）は，インメモリのキー・バリュー型データストア．文字列・リスト・セット・ハッシュ等の豊富なデータ構造，永続化，Pub/Sub，クラスタリングをサポートし，キャッシュ・セッション管理・リアルタイム処理の基盤として広く使われる．

## 詳細

### 主なデータ構造

| 型 | 説明 | ユースケース |
|----|------|------------|
| String | バイナリセーフな文字列 | カウンタ，キャッシュ |
| List | 双方向リスト | キュー，タイムライン |
| Set | 重複なし集合 | タグ，フレンドリスト |
| Sorted Set | スコア付き集合 | ランキング，リーダーボード |
| Hash | フィールド・値のマップ | ユーザープロファイル |
| Stream | 追記専用ログ | イベントログ，CDC |
| Pub/Sub | チャネルベース配信 | リアルタイム通知 |

### 永続化

| 方式 | 説明 | 特徴 |
|------|------|------|
| RDB | 定期スナップショットをダンプ | 起動高速，最後のスナップ以降のデータは失う可能性 |
| AOF | 全書き込みコマンドをログ追記 | 高耐久，ファイルサイズが大きくなりやすい |
| RDB + AOF | 両方を組み合わせ | 推奨構成 |

### クラスタリング

- **Redis Sentinel**: プライマリ・レプリカ構成の自動フェイルオーバー
- **Redis Cluster**: 16384 スロットのシャーディング，自動フェイルオーバー
- スロットは `CRC16(key) % 16384` で計算される

### [[Memcached]] との比較

| 比較項目 | Redis | [[Memcached]] |
|---------|-------|------------|
| データ構造 | 多様 | 文字列のみ |
| 永続化 | あり | なし |
| Pub/Sub | あり | なし |
| トランザクション | MULTI/EXEC | なし |
| 主な用途 | キャッシュ・セッション・キュー・ランキング | 純粋なキャッシュ |

### 主なユースケース

1. **セッションストア**: ステートレスアプリのセッション管理
2. **キャッシュ**: DB クエリ結果，API レスポンス
3. **リアルタイムランキング**: Sorted Set でスコアの動的更新
4. **タスクキュー**: List + BLPOP によるワーカーキュー
5. **Pub/Sub**: チャット，リアルタイム通知
6. **レートリミッタ**: INCR + EXPIRE によるスライディングウィンドウ

## ポイント

- シングルスレッドモデル（I/O多重化）により，コマンドがアトミックに実行される
- Redis 7.x（2022〜）ではRedis Functions，ACL v2，マルチパートAOFが追加
- Valkey（Redisのフォーク）が2024年にLinux Foundation傘下で登場
- マネージドサービス: AWS ElastiCache for Redis / Valkey，GCP Memorystore
