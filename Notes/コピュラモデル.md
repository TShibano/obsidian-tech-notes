## 概要

コピュラモデル（Copula Model）は，複数の確率変数の「周辺分布」と「変数間の依存構造」を分離してモデル化する手法．コピュラは多変量の累積分布関数を，各変数の周辺分布関数どうしの関係として表す関数であり，単一の数値である相関係数と異なり，非線形・非対称な依存関係も含む多様な依存構造を表現できる．

## 詳細

### 基本アイデア（Sklarの定理）

任意の多変量同時分布 $F(x_1, \ldots, x_d)$ は，各変数の周辺累積分布関数 $F_1, \ldots, F_d$ と，依存構造を表すコピュラ関数 $C$ を用いて

$$F(x_1, \ldots, x_d) = C(F_1(x_1), \ldots, F_d(x_d))$$

の形に分解できる（Sklarの定理）．これにより，「各変数がどんな分布に従うか」と「変数同士がどう依存し合うか」を独立に設計できる点が，コピュラモデルの本質的な利点になる．

### 相関係数との違い

ピアソンの相関係数は2変数の**線形**な関係の強さを1つの数値で表すのに対し，コピュラは**関数**として依存構造全体を表現する．そのため，裾（極端な値の領域）でのみ強く相関する「テール依存性」のような，線形相関係数では捉えられない複雑な依存関係も表現できる．

### 代表的なコピュラの種類

| コピュラ | 特徴 |
|---------|------|
| **ガウスコピュラ** | 多変量正規分布から導かれる．裾でのテール依存性を持たない（極端な同時変動を過小評価しやすい） |
| **tコピュラ** | ガウスコピュラを拡張し，上下双方の裾に対称的なテール依存性を持たせられる |
| **アルキメデス型コピュラ**（Clayton，Gumbel，Frank 等） | パラメータ1つで非対称なテール依存性（下側だけ強い依存等）を柔軟に表現できる |

### モデル構築の流れ

1. 各変数の周辺分布 $F_1, \ldots, F_d$ を個別に推定・選択する
2. 各変数の値を周辺分布で変換し，一様分布 $[0,1]$ 上の値に変換する（確率積分変換）
3. 変換後のデータに対してコピュラ関数（依存構造）をフィッティングする
4. 周辺分布とコピュラを合成し，同時分布としてサンプリング・推論する

### 主な応用分野

| 分野 | 用途 |
|------|------|
| **金融工学** | ポートフォリオのリスク評価，信用リスクのデフォルト同時確率のモデリング（2008年金融危機ではガウスコピュラの誤用が一因として指摘された） |
| **保険** | 複数リスクの同時発生確率の評価 |
| **水文学・気象学** | 降水量と流量など，複数の極端事象の同時発生確率 |
| **ベイズ統計との組み合わせ** | 周辺分布・コピュラパラメータの双方を[[ベイズ統計]]的に推定するベイズコピュラモデル |

## ポイント

- コピュラは周辺分布と依存構造を分離してモデル化する枠組みで，Sklarの定理がその理論的基盤
- 相関係数（1つの数値）と異なり，非線形・非対称な依存関係（テール依存性）まで表現できる
- ガウスコピュラはテール依存性を持たず，極端な同時変動のリスクを過小評価しやすい点に注意が必要（2008年金融危機での教訓）
- 金融リスク評価・保険・水文学など，複数の変数が同時に極端な値を取るリスクを評価する分野で広く使われる
