## 概要

状態空間モデル（State Space Model, SSM）は，直接観測できない「真の状態」を，観測可能なデータから逐次的に推定するための時系列解析の枠組み．時間とともに変化する潜在状態を表す「状態方程式」と，状態から観測値がどう生成されるかを表す「観測方程式」の2つで構成され，ベイズ統計と自然に結びつく．

## 詳細

### モデルの構成

状態空間モデルは以下の2本の方程式からなる:

$$\text{状態方程式：} \quad x_t = f(x_{t-1}) + w_t$$
$$\text{観測方程式：} \quad y_t = h(x_t) + v_t$$

| 要素 | 意味 |
|------|------|
| $x_t$ | 時刻 $t$ における（直接観測できない）潜在状態 |
| $y_t$ | 時刻 $t$ における観測値 |
| $f, h$ | 状態遷移・観測を表す関数（線形／非線形） |
| $w_t, v_t$ | システムノイズ・観測ノイズ |

「見えない情報を見えるデータから推定する」という直感的な枠組みであり，トレンド・季節性・ノイズを分解する時系列分析や，ロボティクスの自己位置推定など幅広い分野で使われる．

### カルマンフィルタ

状態方程式・観測方程式がともに線形でノイズがガウス分布に従う「線形ガウス状態空間モデル」の場合，カルマンフィルタというアルゴリズムで状態を効率的かつ厳密に推定できる．カルマンフィルタは計算効率が高くメモリ使用量も少ないため，リアルタイム処理や組み込みデバイスでの実装にも適している．

- **フィルタリング**: 時刻 $t$ までの観測から時刻 $t$ の状態を推定
- **平滑化**: 全期間の観測を使って過去の各時刻の状態を事後的に再推定
- **予測**: 現在までの観測から将来の状態を予測

非線形・非ガウスの場合は，拡張カルマンフィルタ（EKF），無香料カルマンフィルタ（UKF），粒子フィルタ（パーティクルフィルタ）などの近似手法が使われる．

### ベイズ統計との関係

状態方程式は「前時刻の状態を事前分布とし，ノイズによって次状態の分布を得る」という構造そのものがベイズ更新のプロセスと一致する．観測値が得られるたびに事後分布を更新していく点で，[[ベイズ統計]]の逐次学習の枠組みと自然に整合する．[[ギブスサンプラー]]やパーティクルフィルタは，非線形・非ガウスなモデルに対してベイズ的に状態を推定する代表的な手法．

### 主な応用

| 分野 | 用途 |
|------|------|
| 時系列分析 | トレンド・季節成分・ノイズへの分解，需要予測 |
| 経済学 | 潜在的な景気循環指数の推定 |
| ロボティクス | 自己位置推定（SLAM），センサーフュージョン |
| 金融工学 | ボラティリティの推定 |
| 制御工学 | 航空機・ミサイルの誘導制御（カルマンフィルタの起源） |

## ポイント

- 直接観測できない潜在状態を，状態方程式・観測方程式の2本立てで逐次推定する時系列モデルの枠組み
- 線形ガウスの場合はカルマンフィルタで厳密かつ効率的に解ける
- 非線形・非ガウスの場合は拡張/無香料カルマンフィルタや粒子フィルタで近似する
- 状態遷移がベイズ更新の構造そのものであり，ベイズ統計と自然に結びつく
- 時系列分析からロボティクスの自己位置推定まで応用範囲が広い
