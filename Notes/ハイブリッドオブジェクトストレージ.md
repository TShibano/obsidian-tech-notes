## 概要

ハイブリッドオブジェクトストレージは，オンプレミスと複数クラウドにまたがるオブジェクトストレージを統合し，単一の名前空間・APIで管理するアーキテクチャ．コンプライアンス要件を満たしながらクラウドの柔軟性を活かすために採用される．

## 詳細

### 背景

- **オンプレミス[[オブジェクトストレージ]]**: 自社データセンターに設置，データ主権・低レイテンシを確保（例: Cloudian, NetApp StorageGRID, Dell EMC ECS, [[MinIO]]）
- **クラウドオブジェクトストレージ**: 無制限スケール，従量課金，グローバルアクセス（例: [[Amazon S3]], GCS, Azure Blob Storage）

### ハイブリッド構成の仕組み

```
オンプレミス (StorageGRID / MinIO)  ←── VPN / Direct Connect ──→  クラウド (S3 等)
          ↑                                                              ↑
   低レイテンシ・高セキュリティデータ                           スケールアウト・バックアップ
```

1. VPN または専用線（AWS Direct Connect, GCP Interconnect）でオンプレとクラウドを接続
2. ティアリングポリシーでホットデータはオンプレ，コールドデータはクラウドへ自動移動
3. S3 互換 API により，アプリケーション側は接続先を意識せずアクセス

### 代表的なソリューション

| 製品 | 種別 | 特徴 |
|------|------|------|
| [[MinIO]] | OSS / オンプレ | S3 互換，高性能 |
| NetApp StorageGRID | エンタープライズ | マルチクラウドゲートウェイ |
| Cloudian HyperStore | エンタープライズ | S3 互換，ハイブリッド |
| AWS Storage Gateway | クラウドゲートウェイ | オンプレ→S3へのシームレス統合 |

### 主なユースケース

- **データ主権・コンプライアンス**: 個人情報や規制対象データをオンプレに保持しつつ，分析はクラウドで実施
- **バックアップ・DR**: オンプレのプライマリデータをクラウドにレプリケーション
- **クラウドバースト**: 通常はオンプレで処理し，ピーク時のみクラウドにオーバーフロー
- **[[データレイク]]の分散配置**: 異なるロケーションにある大量データを論理的に統合

## ポイント

- オンプレ回帰（Repatriation）トレンドを受け，ハイブリッド構成の需要が増加
- コスト最適化のため，ネットワーク転送費用（エグレスコスト）の見積もりが重要
- S3 互換 API が事実上の業界標準で，[[MinIO]] により完全な互換性でオンプレ展開が可能
