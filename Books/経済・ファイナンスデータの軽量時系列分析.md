
# 流し読み
- 本書の目的
	- 時期列分析の基礎的な考え方を丁寧に説明し，より高度な教科書への橋渡し
	- 時系列モデルを実際のデータに応用する際に必要となる知識を紹介する
- 時系列分析の目的は，時系列データが持っている多様な特徴を記述できるモデルを構築すること
	- モデルを用いて，目的に応じた分析を行う
		- 将来の予測
		- 変数間の動学的関係(分散投資・リスク管理・経済政策などに用いられる)
		- 経済理論やファイナンス理論の検証
- 時系列データの種類
	- 原系列：時系列データそのもの
	- 対数系列：対数変換したもの
	- 差分系列(階差系列)：ある時点離れたデータとの差
	- 対数差分系列：変化率(成長率)．対数系列にしたものの差分系列
	- 季節調整済み系列：季節調整(季節的な変動を取り除くこと)を行った系列
- 基本統計量と時系列モデル
	- 平均
	- 分散
	- 標準偏差(ボラティリティ)：リスクを計算するのによく使われる
	- 自己共分散：k時点離れたものとの共分散．これをkの関数としてみたものは自己共分散関数という
	- 自己相関係数：自己共分散を基準化したもの．自己共分散と同様に，kの関数としたものを自己相関関数と言い，これをグラフにしたものを，コレログラムという．
	- 時系列データを，ある確率変数列からの1つの実現値とみなし，その確率変数列の生成過程に関して，ならなkの性質や構造を過程する．このような確率変数列を確率過程やデータ生成過程という．
- 定常性
	- 弱定常性
	- 強定常性
- ホワイトノイズ
	- iid系列
	- ホワイトノイズ
- 自己相関の検定
	- 時系列分析において，自己相関があるかどうかは非常に重要である．
		- 自己相関がない場合，時系列分析でできることは限られる
- モデル
	- AR：自己回帰過程
	- ARMR：自己回帰移動平均過程
	- VAR：自己回帰モデルに変数を追加したもの．変数を並べる順序が重要となる
	- 単位根過程
	- ARIMA：自己回帰和分移動平均過程
	- GARCH：ボラティリティ(標準偏差)をモデル化する
