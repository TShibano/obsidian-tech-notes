# ノート最新化

Vault ルートの `update-queue.toml` に書かれたノートを読み込み，当日時点の最新情報で更新します．
更新が完了した項目はキューから削除します．

## 使用方法

```
/update-note [最大処理数]
```

- `最大処理数`: 省略時は 3（コンテキスト制限を考慮）

## キューファイルの書式

`update-queue.toml`（Vault ルート）:

```toml
[[notes]]
name = "Claude Model"            # 必須: Notes/ のファイル名（拡張子なし）
focus = "最新モデルと料金の反映"   # 任意: 重点的に調べる観点

[[notes]]
name = "llama.cpp"
```

- `focus` がなければ「最新バージョン・仕様変更・非推奨化・新しい動向」を幅広く確認する
- 上から順に処理する

## 処理手順

### 1. 引数とキューの読み取り

1. `$ARGUMENTS` の第1引数を最大処理数とする（省略時は 3）
2. `update-queue.toml` を読み取る．ファイルがない，または `[[notes]]` が空なら，書式例を示して終了する
3. 先頭から最大処理数ぶんの項目を対象にする
4. 各項目の `Notes/{name}.md` が存在するか確認する．存在しない項目はスキップして報告に含める（新規作成は `/tech-note` の役割なので行わない）

### 2. 既存ノートの把握

対象ノートごとに以下を行う:

- 本文全体を読み，記述されている事実（バージョン，日付，仕様，料金，対応状況など）を洗い出す
- frontmatter の `date` / `updated` から前回の記述時点を把握する
- 「参考」セクションの一次情報源を確認する

### 3. WebSearch による最新情報の調査

以下の観点で WebSearch を実行する:

1. **フォーカス内容**: `focus` に指定された観点
2. **バージョン・リリース**: 前回記述以降の新バージョン，リリースノート，changelog
3. **仕様変更・非推奨化**: 廃止・名称変更・破壊的変更など，既存記述が誤りになる変更
4. **最新動向**: 前回記述以降の主要な発表やトレンド

**注意事項:**
- 一次情報源を優先する（公式ドキュメント，公式ブログ，リリースノート，論文など）
- まとめ記事経由の情報は追加検索で一次情報源を特定してから反映する
- 確証の取れない情報は反映しない

### 4. ノートの更新

- **既存構成を維持する**: セクション構成（概要 / 詳細 / ポイント / 関連項目 / 参考）と既存の文体を保つ
- **古くなった記述は書き換える**: 誤りになった事実は修正し，必要なら「（YYYY-MM-DD 時点）」と時点を明記する
- **新情報は該当セクションに追記する**: 末尾にまとめて足すのではなく，内容に合った位置に組み込む
- **ノート末尾に更新履歴を残す**: 「参考」の後に `## 更新履歴` セクションを設け（なければ作成），`- YYYY-MM-DD: 変更点の要約` を1行追記する
- **参考を更新する**: 新たに使った一次情報源を「参考」に追加する．リンク切れ・旧情報のリンクは差し替える
- **frontmatter**: `date`（初回作成日）は変更せず，`updated: YYYY-MM-DD` を追加または更新する．`tags` はタグ体系に沿って必要な場合のみ見直す
- 調査の結果，更新すべき内容がなかった場合はノートを変更しない（`updated` も変えない）．報告には「変更なし」と記載する

### 5. 双方向リンクの整合性維持

更新で新たに `[[ノート名]]` リンクを追加した場合，`/tech-note` と同様に逆リンクを追加する:

1. リンク先ノートの `related` frontmatter に `"[[今回のノート名]]"` を追加
2. リンク先ノートの「関連項目」セクションに `- [[今回のノート名]]` を追加

既に逆リンクが存在する場合は追加しない．

### 6. キューの更新

- 更新完了（「変更なし」を含む）した項目を `update-queue.toml` から削除する
- スキップした項目（ノートが存在しない等）はキューに残す
- 未処理の項目はそのまま残す

### 7. 結果の報告

```
## ノート最新化 結果

| ノート | 結果 | 主な変更点 |
|--------|------|-----------|
| [[Claude Model]] | ✅ 更新 | Opus 5.5 を追加，料金表を更新 |
| [[llama.cpp]] | ➖ 変更なし | - |
| [[Foo]] | ⚠️ スキップ | Notes/Foo.md が存在しない |

キュー残り: N 件
```

### 8. コミットとプッシュ

1. 更新したノート，逆リンクを追加したノート，`update-queue.toml` を `git add` でステージング
2. 以下の形式でコミットメッセージを作成し `git commit` する:
   - 形式: `ノート更新(YYYY/MM/DD): ノート名1, ノート名2, ...`
   - 例: `ノート更新(2026/11/09): Claude Model, llama.cpp`
3. `git push` でリモートにプッシュ
4. 更新したノートが1件もなく，キューにも変化がない場合はコミットしない
